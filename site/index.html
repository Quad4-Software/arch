Quad4

Arch repository

Pacman repository for Quad4 software. Add it to /etc/pacman.conf and install with pacman -S.

Install

Append this after the official [core] and [extra] blocks, or use pacman-quad4.conf.

[quad4]
SigLevel = Optional TrustAll
Server = https://arch.quad4.io/$arch
Server = https://github.com/Quad4-Software/arch/releases/download/pkg-$arch
sudo pacman -Syu
sudo pacman -S reticulum-go meshchatx

Packages are unsigned until a packaging key is published. Keep SigLevel = Optional TrustAll until then.
